# AZURE API MANAGEMENT GATEWAY

## PART I. CATEGORIES

* API GATEWAY CAPABILITIES
-accepts API calls and routes to your backend services
-verifies API keys, JWT tokens, certificates and other credentials
-enforce usage quotas and rate limits
-caches backend responses
-versioning

* AZURE PORTAL CAPABILITIES
-define or import SCHEMA
-set up policies like quotas or transformations on the APIs
-package APIs into products
-manage users

* DEVELOPER PORTAL CAPABILITIES
-read API documentations
-create an account and subscribe to get API keys
-try out on API via the interactive console
-access analytics
